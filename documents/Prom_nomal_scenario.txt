* 역할
  : 너는 20년차 OnDevice와 AI 분야에서 활약중인 시스템엔지니어 전문가이다.

* 프로젝트 배경
  : 고령화 사회가 될 수록 고령의 운전자의 사고가 늘어나는 추세이다. 따라서 고령의 운전자의 안전 운전을 돕는 인포테인먼트 설정을 자동화하여 운전자의 안전에 도움을 주고자 한다.

* 지시 사항
  : OnDevice에서 카메라 기반으로 운전자와 동승자의 얼굴을 인식하여 성별과 나이를 추측하여 인포테인먼트 설정을 자동화하는 정상 동작을 하는 시나리오를 구현해줘.

* 시스템 구성
  : OnDevice에 설치될 수 있는 OS
  : USB 카메라
  : 얼굴 검출 및 성별/나이 추측 모델(DeepFace. https://github.com/serengil/deepface.git)
  : DeepFace의 분석결과를 받아 나이대 확률을 반환하는 AI 추론 모듈
  : 나이대 확률을 기반으로 인포테인먼트 설정(안내 멘트 음성 볼륨, 음성 안내 속도, 화면 밝기 등)을 결정하는 모듈
  : Log 기록 모듈

* 시스템 시작 조건
  : 카메라 신호와 인포테인먼트 시스템이 모두 정상이고, 카메라의 최근 5개 frame 중 3개 이상에서 동일인의 얼굴이 검출되면 시스템 시작

* 정책 조건
  : 카메라 신호와 인포테인먼트 시스템의 상태 중 하나라도 false면 차량 이상 안내 멘트 알림 후 시스템 종료
  : 나이대 확률이 0.7 이상일 때 인포테인먼트 설정
  : 1) 나이가 70대 이상일 경우
    - 안내 멘트 음성 볼륨: 80%
    - 음성 안내 속도: 0.8배속
    - 화면 밝기: 100%
  : 2) 나이가 50~60대일 경우
    - 안내 멘트 음성 볼륨: 70%
    - 음성 안내 속도: 1.0배속
    - 화면 밝기: 90%
  : 3) 나이가 40대 이하일 경우
    - 안내 멘트 음성 볼륨: 60%
    - 음성 안내 속도: 1.2배속
    - 화면 밝기: 80%
  : 인포테인먼트 설정이 완료되면 소리로 변경 내역을 알림
  : 만약 카메라에 여러 사람이 있다면 운전석을 1순위로 하여 설정 진행
  : 운전석이 공석이라면 다른 여러 사람 중 나이대가 가장 많이 겹치는 나이대를 기준으로 인포테인먼트 설정
  : 30초 동안 사람의 얼굴이 검출되지 않으면 시스템 종료

* 작성 요구사항
  1. 시나리오 ID와 이름을 작성한다.
  2. 목적과 참여자를 작성한다.
  3. 사전조건을 측정 가능한 표현으로 작성한다.
  4. 정상 흐름을 한 단계에 한 행동만 포함하여 작성한다.
  5. AI 추론과 결정 정책을 별도 단계로 작성한다.
  6. 성공 시 사후조건을 작성한다.
  7. 성능, 안전, 로그 성공 기준을 작성한다.
  8. 원본 얼굴 영상은 저장하지 않는다.
  9. Markdown 형식으로 출력한다.
  10. 초보자가 이해할 수 있도록 각 단계에 짧은 설명을 덧붙인다.

  - 시작 조건과 종료 조건이 명확한가?
  - 신뢰도 기준이 명시되어 있는가?
