# Proj_Age_and_gender_estimation_based_on_facial_images

* Update: 2026.07.28.
## 1. Description
* 사람 얼굴 사진으로부터 성별과 나이를 추측하여 안내 멘트의 속도와 볼륨을 조절
* 적용 가능 분야: ADAS(DMS)_운전자의 성별과 나이를 추측하여 차량의 인포테인먼트를 설정함
* 추측 모델: DeepFace(https://github.com/serengil/deepface.git)
---

## 2. Environment
* **OS:** Ubuntu 22.04 LTS(Jammy Jellyfish)
* **Language:** Python(ver: 3.11)
---

## 3. Pre-installation
* $ python -m pip install pyyaml typeguard
* $ python -m pip install tf-keras
